# Fibra

Plataforma completa para gerenciamento de academias, acompanhamento de treinos, alimentação e evolução física dos usuários. O sistema busca centralizar funcionalidades normalmente distribuídas em diversos aplicativos, oferecendo uma experiência integrada para alunos, treinadores e administradores.

---

### 🎯 Objetivo do Projeto

Desenvolver uma plataforma web capaz de integrar gerenciamento de treinos, alimentação, avaliações físicas, acompanhamento de evolução corporal e administração de academias em um único ambiente, proporcionando uma experiência simples, organizada e personalizada para alunos e profissionais.

### 💡 Visão do Produto

Nosso objetivo é eliminar a necessidade de utilizar diversos aplicativos para acompanhar a vida fitness. O sistema reunirá treino, alimentação, métricas corporais, evolução física e comunicação entre aluno e treinador em uma única plataforma.

### 🚨 Problema que resolvemos

Atualmente, usuários utilizam diferentes aplicativos para registrar treinos, controlar alimentação, acompanhar peso e conversar com seus treinadores. Como essas informações permanecem separadas, torna-se difícil visualizar a relação entre alimentação, desempenho e evolução física. Nossa plataforma centraliza esses dados e gera uma visão integrada do progresso do usuário.
